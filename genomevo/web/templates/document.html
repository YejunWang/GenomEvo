1. Introduction

GenomEvo is an Ancestral Orthologous Genome (AOG)-centered pipeline for automated bacterial comparative and evolutionary genomic analysis. It was designed to address the computational challenges posed by the rapid accumulation of bacterial genome sequences. The system integrates seven core modules that together enable: ancestral genome reconstruction, core and pan-genome analysis, genome annotation, 1D genomic representation, evolutionary trajectory (structural variant) analysis, and interactive visualization.

The central concept of GenomEvo is the Backbone-Patching (BP) strategy implemented in BactAG 2.0. This phylogenetically guided, bottom-up, step-wise approach progressively resolves ancestral genomes by comparing pairs of sister lineages against an outgroup, extracting the conserved backbone, and filling gaps with lineage-specific sequences. The resulting AOGs serve as the reference framework for all downstream analyses.

GenomEvo has been successfully applied to Escherichia coli (including Shigella spp.), Salmonella enterica, and other bacterial taxa, revealing large-scale synteny conservation, recombination hotspots, and frequent inversion events in specific lineages.

2. Analysis Workflow

3. Module Reference

3.1 BactCG — Core Genome Analysis

Identifies the core genome from protein FASTA files via CD-HIT clustering and BLASTP-based reciprocal best-hit orthology determination. Outputs MEG-format alignments suitable for phylogenetic analysis, providing the evolutionary relationships among strains needed for subsequent ancestral genome reconstruction.

ParameterTypeDefaultDescription
-istring—Input protein FASTA directory
-ostring—Output directory
--refstring—Reference strain name
--cd-cfloat0.7CD-HIT identity threshold
--cd-sfloat0.7CD-HIT length difference cutoff
--cg1float0.8Primary orthology cutoff
--cg2float0.9Secondary orthology cutoff

3.2 BactAG — Ancestral Genome Reconstruction

Reconstructs bacterial ancestral genomes (AOGs) for each internal node of a phylogenetic tree using the Backbone-Patching strategy. The tree can be obtained from BactCG output. For each pair of sister lineages, progressiveMauve identifies the conserved backbone; lineage-specific sequences are then patched in by comparison with the outgroup. The process iterates from the tips to the root of the tree.

ParameterTypeDefaultDescription
--treestring—Directory containing a single Newick tree file
--genestring—Directory of genome FASTA files (.fasta)
-tint20Parallel threads
-idstringbactID.txtOutput lineage map path

3.3 BactPG — Pan-Genome Analysis

Builds a pan-genome presence-absence matrix across all input strains. Uses iterative batch BLAST with automatic consolidation. Output PG.txt is consumed by BactPGA for annotation.

ParameterTypeDefaultDescription
--seqstring—Sequence FASTA directory
--similarityfloat0.7Clustering similarity threshold
-tint30Parallel BLAST threads

3.4 BactPGA — Pan-Genome Annotation

Annotates genomic features (CDS, rRNA, tRNA, ncRNA, misc_feature) with pan-genome cluster UIDs using mutual best hit alignments. Pure Go implementation with zero external dependencies. Input GBK files can be obtained via PGAP.

ParameterTypeDefaultDescription
--gbkstring—Input GenBank file
--pgstring—PG.txt matrix path
--seqstring—Protein sequence directory (pipeline mode)
--cov1float0.7Coverage threshold 1
--cov2float0.7Coverage threshold 2

3.5 Bact1DGR — 1D Genomic Representation

Generates 1D linear coordinate maps comparing an ancestral genome to its descendants through progressiveMauve pairwise alignments and orthologous block extraction.

ParameterTypeDefaultDescription
--basestring—Base/ancestral strain name
--patchescsv—Comma-separated patch strain list
--bactidstring—bactID.txt file (auto-resolves patches)
-fstring.FASTA directory
-wint8Parallel workers

3.6 BactEvolTraj — Evolutionary Trajectory

Analyzes large structural variants (insertions, deletions, inversions) along tree branches via three-way progressiveMauve alignment. Maps each SV event to affected genes using GenBank annotations (GBK files, obtainable via PGAP).

ParameterTypeDefaultDescription
--root-nodestring—Root ancestral genome name
--fasta-dirstring.FASTA directory
--gbk-dirstring.GenBank directory
--treeJSON[]Tree edges as JSON array
--min-lenint1000Minimum SV event length (bp)

3.7 BactFragAnn — Fragment Annotation & Visualization

Generates interactive Plotly-based HTML dashboards with seamless integration to upstream modules. Two modes: 1dgr takes Bact1DGR output (.1dgr.txt + .gbk) and produces mosaic charts mapping genomic fragments to source strains with clickable gene-level details; evoltraj takes BactEvolTraj SV event tables and produces dual circular plots (insertions / deletions) with gene annotation popups. GBK/GFF annotation files can be generated using PGAP.

ParameterTypeDefaultDescription
--modestring1dgr"1dgr" (from Bact1DGR) or "evoltraj" (from BactEvolTraj)
--base-dirstring.Working directory (Bact1DGR / BactEvolTraj results)
output_folderstringMosaic_ChartsOutput subfolder name
txt_folderstring1DGR_en1DGR text file folder (1dgr mode)
gbk_folderstringGBK_enGenBank file folder
sv_filestringautoSV event CSV/TXT path (evoltraj mode)

4. Worked Example: Escherichia coli Genome Evolution

This example reproduces the E. coli species-level ancestral genome analysis described in the GenomEvo manuscript (Wang et al., 2025). We will reconstruct the ancestral genomes of major E. coli lineages, identify the core and pan-genome, and analyze evolutionary trajectories. The input data consists of representative E. coli and Shigella spp. strains.

4.1 Prepare Input Data

Organize your data into the following directory structure:

# Directory layout ecoli_project/ ├── genomes/ # FASTA genome files (one per strain) │ ├── MG1655.fasta │ ├── O157_H7.fasta │ ├── S_flexneri.fasta │ └── ... ├── proteins/ # Protein FASTA files (one per strain) │ ├── MG1655.fasta │ ├── O157_H7.fasta │ └── ... ├── annotations/ # GenBank (.gbk) / GFF annotation files │ ├── MG1655.gbk │ └── ... └── tree/ # Phylogenetic tree └── ecoli_core_tree.nwk

💡 Getting annotations: GFF and GBK annotation files can be generated using NCBI's PGAP (Prokaryotic Genome Annotation Pipeline). Simply submit your genome FASTA files to PGAP to obtain standardized, publication-quality annotations in both GFF and GBK formats.

The phylogenetic tree should be in Newick format with strain names matching the FASTA filenames (without extension). Example tree content:

# ecoli_core_tree.nwk (simplified example) (((MG1655,O157_H7),S_flexneri),E_fergusonii);

4.2 Step 1: Core Genome Analysis (BactCG)

First, identify the core genome from protein sequences to infer the phylogenetic relationships among strains. BactCG produces MEG-format alignments that can be used to construct a phylogenetic tree:

genomevo bactcg \ --input ./ecoli_project/proteins \ --output BactCG_Results \ --ref MG1655 \ --cd-c 0.7 \ --cg1 0.8

Expected output: Core gene clusters, MEG-format multiple sequence alignments, and SNP matrices. Use the MEG alignments to build a phylogenetic tree (e.g., with RAxML or IQ-TREE), then place the resulting Newick tree file in ./ecoli_project/tree/ for the next step.

4.3 Step 2: Reconstruct Ancestral Genomes (BactAG)

With the phylogenetic tree from Step 1 and genome sequences, run BactAG to reconstruct the ancestral genome for every internal node:

genomevo bactag \ --tree ./ecoli_project/tree \ --gene ./ecoli_project/genomes \ --threads 20 \ --output BactAG_Results

Expected output:

  • BactAG_Results/output/ — Reconstructed AOGs in FASTA format (e.g., AG_0001.fasta)
  • BactAG_Results/bactID.txt — Lineage map recording all parent-child relationships
  • BactAG_Results/log/ — Processing logs for each ancestral node

Excerpt from bactID.txt:

# This is BactID 2025-01-15 10:30:00 MG1655+O157_H7 OutsidE S_flexneri = AG_0001 AG_0001+S_flexneri OutsidE E_fergusonii = AG_0002

4.4 Step 3: Pan-Genome Analysis (BactPG) — Run in Parallel with Step 2

While BactAG is running, start BactPG in parallel to catalog the pan-genome across all strains. Both BactAG and BactPG operate at the same level after BactCG:

genomevo bactpg \ --seq ./ecoli_project/proteins \ --similarity 0.7 \ --threads 30 \ --output BactPG_Results

Expected output: BactPG_Results/PG.txt — a tab-separated pan-genome presence-absence matrix.

Example PG.txt snippet:

# Gene_ID MG1655 O157_H7 S_flexneri ... PG_00001 1 1 1 PG_00002 1 1 0 PG_00003 1 0 1

"1" indicates presence, "0" indicates absence of the gene in that strain.

4.5 Step 4: Pan-Genome Annotation (BactPGA) — Integrates AG + PG

With both ancestral genomes (from BactAG) and the pan-genome matrix (from BactPG) ready, run BactPGA to annotate ancestral genome features with PG cluster UIDs. This step combines the outputs of the two parallel branches:

genomevo bactpga \ --mode pipeline \ --gbk ./BactAG_Results/output/AG_0002.gbk \ --pg ./BactPG_Results/PG.txt \ --seq ./ecoli_project/proteins \ --cov1 0.7 \ --cov2 0.7 \ --output BactPGA_Results

4.6 Step 5: 1D Genomic Representation (Bact1DGR)

Generate 1D linear representations to compare an ancestral genome with its descendants:

genomevo bact1dgr \ --base AG_0002 \ --bactid ./BactAG_Results/bactID.txt \ --fasta-dir ./BactAG_Results/output \ --workers 8 \ --output OneDGR_Results

Expected output: OneDGR_Results/Final_Results/AG_0002.1DGR.txt — coordinate map with columns: Block_ID, Start, End, Strand, Source_Strain.

4.7 Step 6: Evolutionary Trajectory Analysis (BactEvolTraj)

Analyze structural variants along the evolutionary tree branches:

genomevo bactevoltraj \ --root-node AG_0002 \ --fasta-dir ./BactAG_Results/output \ --gbk-dir ./BactAG_Results/output \ --tree '[["AG_0002","AG_0001"],["AG_0001","MG1655"]]' \ --min-len 1000 \ --output EvolTraj_Results

Expected output: CSV files containing insertion/deletion/inversion events per branch, coverage matrices, and Matplotlib plots.

4.8 Step 7: Interactive Visualization (BactFragAnn)

Generate interactive HTML dashboards, directly consuming the outputs from previous steps:

# 1DGR mosaic charts (consumes Bact1DGR output) genomevo bactfragann \ --mode 1dgr \ --base-dir ./OneDGR_Results \ --txt-folder Final_Results \ --gbk-folder ./ecoli_project/annotations \ --output-folder Mosaic_Charts # SV event circular plots (consumes BactEvolTraj output) genomevo bactfragann \ --mode evoltraj \ --base-dir ./EvolTraj_Results \ --sv-file Large_SV_Details.csv \ --output-folder SV_Plots

4.9 Full Pipeline (Single Command)

Alternatively, define all steps in a JSON configuration file and run the entire pipeline at once:

# pipeline.json { "steps": [ {"module": "bactcg", "params": {"input_dir": "./proteins", "output_dir": "./cg_out", "ref_strain": "MG1655"}}, {"module": "bactag", "params": {"tree_dir": "./tree", "gene_dir": "./genomes", "threads": 20}}, {"module": "bactpg", "params": {"seq_dir": "./proteins", "similarity": 0.7, "threads": 30}}, {"module": "bactpga", "params": {"mode": "pipeline", "gbk_file": "./ag_out/AG_0002.gbk", "pg_file": "./pg_out/PG.txt", "seq_dir": "./proteins"}}, {"module": "bact1dgr","params": {"base_strain": "AG_0002", "bactid_file": "./bactID.txt", "fasta_dir": "./genomes"}} ] }
genomevo pipeline --config pipeline.json
Expected runtime: For a dataset of ~50 E. coli genomes, the complete pipeline (BactAG + BactCG + BactPG) typically completes within 4–8 hours on a 20-core server, depending on genome sizes and the depth of the phylogenetic tree. BactAG is the most computationally intensive step, as it performs progressiveMauve alignments for every internal node.

5. Installation & Dependencies

5.1 System Requirements

  • Linux (primary) or macOS; Windows via WSL
  • Python ≥ 3.8
  • Go ≥ 1.18 (only if rebuilding binaries; pre-compiled binaries are included)

5.2 External Tools

ToolRequired ByInstallation (Ubuntu/Debian)
progressiveMauveBactAG, Bact1DGR, BactEvolTrajsudo apt install mauve-aligner
blastn / blastpBactCG, BactPGsudo apt install ncbi-blast+
cd-hitBactCG, BactPGsudo apt install cd-hit

5.3 Install GenomEvo

# Clone the repository git clone https://github.com/YejunWang/GenomEvo.git cd GenomEvo/Genomevo # Using the pre-configured mamba environment (recommended) mamba run -n bactet genomevo check # Or create a new environment mamba create -n genomevo python=3.10 -y mamba activate genomevo pip install -e . # Verify genomevo check

5.4 Launch Web Interface

genomevo web --port 8080 # Open http://localhost:8080 in your browser
